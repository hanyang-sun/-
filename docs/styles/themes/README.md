# 战斗投影：怪物 / 路线 / 防御塔 的四种卡通风格

背景不参与风格变化。每张图从左到右：怪物、防御塔、行进箭头、路线纹理、范围环。

| 风格 | 怪物 | 路线 | 防御塔 | 范围环 |
| --- | --- | --- | --- | --- |
| 章鱼泡泡（默认） | 菱形宝石怪 | 柔光带 | 章鱼（现有战斗动画） | 圆点虚线环 |
| 软糖 | 圆耳朵软糖熊 | 糖果圆点 | 棒棒糖（圆盘 + 糖棍 + 螺旋） | 实心柔光环 |
| 像素机器人 | 方头天线机器人 | 虚线电路段 | 炮塔（方形底座 + 炮管） | 24 段刻度环 |
| 幽灵 | 圆顶波浪尾幽灵 | 雾状光斑 | 菱形水晶 | 双线虚点环 |

运行时在投影窗口按 **1/2/3/4** 实时切换风格。

## 建议

- **软糖**：最贴合儿童受众，圆润、无尖角，和现有章鱼形象同属“软萌”体系，建议作为主风格；
- **像素机器人**：适合“小男生/科技感”路线，可作第二套或关卡主题；
- **章鱼泡泡**：保留为现有默认，形象已完整；
- **幽灵**：偏夜间/万圣节主题，适合活动皮肤而非日常。

# 连续投影下的识别

播放时投影保持当前画面，不为拍照插入黑帧。相机可以同时拍到积木和投影光。识别使用 `ProjectedLightRecognizer`：用已知的投影指令把这张照片除回反射率，再按原有调色板分类。

## 照片模型

线性光下每个通道：

`相机 = 反射率 ×（环境光 + 投影增益 × 投影指令）+ 黑电平`

投影指令是该格中心实际发出的颜色（0 到 1，已含透明度），不是把投影关掉。反射率是积木或桌面自己的颜色。这是实拍的乘性关系，不是 Unity 里半透明面片的叠加。

## 接真实相机和投影机

一次标定，对局中不要重复：

1. 关闭相机自动曝光、自动增益和自动白平衡，之后不要再改。
2. 盖上镜头拍一帧，作为黑电平。
3. 投影全黑，拍空桌面，再拍每一种积木顶面。
4. 投影全白，再拍同一空桌面。白场要刚好不爆光，给投影留出余量。
5. 用 `PhotometricProfile.Fit` 生成标定。桌面反射率使用已知灰卡；没有灰卡时，用仿真调色板里的桌面颜色只适合合成图，不能代替这次实拍。

对局中每一帧要同时给出：这张照片、曝光是否仍锁定、快门期间投影内容有没有变过、消隐比例。消隐比例必须是 0。快门跨过两幅不同投影，或曝光被自动调节改掉时，这一帧会被拒绝，不会拿去更新布局。

优先使用全局快门。滚动快门时，曝光时间要落在同一幅投影画面内。投影机保持正常刷新即可，不需要为了识别周期性关灯。

投影过亮、塑料高光或通道已经饱和时，该格记为未知而不是猜颜色。把投影亮度降到白场不爆光后，这些格会重新变得可分。

## 仿真

场景里的投影面片继续显示。连续投影取样不隐藏这些面片，也不改写正在显示的相机画面：同一台相机被画到屏幕外的纹理，并暂时不包含投影层，只为取得积木反射率，再合成带投影光的照片交给 `ProjectedLightRecognizer`。

进入播放后默认就是这条路径。按一次 F8 会改到跨帧消隐，投影会熄灭再亮起；再按一次回到连续投影。数据集保存的干净 RGB 仍走原来的无投影采集。

# 原始布局与投影展示双窗口

更新：2026-11-07。适用 Unity 6000.3.24f1 编辑器 Play 模式，不代表 Windows Player 已实现双窗口。

## 操作

进入默认场景 Play 后自动打开“原始积木布局”和“投影展示”，也可使用 `Brick2Life/Windows/Open layout and projection`。原始窗口拥有编辑、识别与战斗操作；点击取得焦点后才能编辑，战斗中也允许编辑墙塔。展示窗口只读。

展示顶部的“积木＋投影 / 仅投影”只控制预览内容，两种模式都支持拖动旋转、滚轮缩放与复位。仅投影保留暗色棋盘，用于平面诊断，不能用于验证积木遮挡。F8/顶部识别模式按钮与该显示设置相互独立。

退出 Play 或使用 `Brick2Life/Windows/Close layout and projection` 关闭窗口组后，释放预览场景、相机、材质和纹理，并恢复原始输入与相机状态。

## 显示来源

- 原始搭建视图保持无投影，方便编辑；顶置相机预览才是识别实际收到的 RGB。
- 展示积木由 B 已确认的 `LevelState` 和公开调色板重建，不直接复制源积木实例。目标来自公开关卡配置。确认前展示可暂时落后实际摆放。
- 预览使用独立场景、相机和 RenderTexture，观察操作不改变源布局、源 RGB 或识别条件。
- 预览复用固定投影仪的输出与参数，在自身表面重新计算投影与遮挡，不再复制角色面片、路线模型或旧三维替身。积木使用预览独占的低光滑度 Standard 材质及中性灯光。
- 新确认后直接通知预览刷新；战斗、暂停、波次间隔及胜败后都更新。底部“确认 / 投影 / 画面”版本稳定后应一致，无需重试刷新。

## 两种识别模式

连续识别直接处理带投影 RGB，不因采样隐藏展示。暂停识别在按暂停后统一关闭表面投影光，保留棋盘和积木；继续/开战的新确认完成后恢复。搭建窗口始终无投影。取消、禁用、异常和超时释放暂停门。

排除 31 内容源层无法移除已经反射到表面的光，实际显示由 `SimulationProjectedLight` 与统一门控制。当前没有周期性消隐帧数或时长参数。

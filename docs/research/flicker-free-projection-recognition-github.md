# 连续投影下的积木识别：复用比较

日期：2026-11-06。范围：投影保持常亮（相机同时拍到积木和投影光）时仍分辨固定棋盘上的空格与调色板颜色，播放过程中不插入消隐帧。后续要接真实相机和投影机，算法必须针对照片的乘性光照，而不是 Unity 里把面片关掉。

验收：同一套纯 C# 光度模型能从“已知投影指令 + 锁定曝光的照片”还原颜色；投影指令的消隐比例大于 0、曝光未锁定或曝光期间画面发生变化时拒绝该帧；强投影把通道打满时该格记为未知，而不是猜一个颜色；仿真接入后播放中的投影不再为了识别跨帧隐藏。

## 采用的机制

真实照片是乘性的：`相机 = 反射率 ×（环境光 + 投影增益 × 投影指令）+ 黑电平`。投影指令是本程序发给投影机的颜色，播放时不插入黑帧，所以人眼看不到为识别而做的频闪。反射率用一次标定测出（镜头盖黑电平、桌面全黑、桌面全白、每种积木在投影全黑下各一帧），对局中只做除法还原，再沿用现有色度分类。

通道被打满时除法不成立，该采样记为未知。自动曝光会改变增益，标定即失效，因此未锁定曝光的帧直接拒绝。滚动快门若跨了两帧投影内容，同样拒绝，而不是去消隐。

仿真里投影面片仍是透明叠加，不等于照片。识别回路在同一函数内短暂渲染一张无投影的反射率图，立刻把投影画回去，再用上述公式合成照片交给识别器。播放出来的投影不会跨帧熄灭。

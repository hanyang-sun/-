# 当前投影贴合与验收

更新：2026-11-07。适用当前固定透视投影仪仿真。校正已实现；修复前正交烘焙的推导、代码片段和备选方案移至 [历史讨论](history/projection-alignment-analysis-2026-11-06.md)。

## 已实现的方法

`ProjectionSimulator` 与 `SimulationBattleOverlay` 把内容放在已确认的目标表面：当前章鱼脸为单层顶面 y=1，地面道路/入口/效果为 y=0。生成输出的内容相机使用透视，并同步投影仪的位置、角度、视场角和裁剪范围；生成和回投使用同一相机的实际矩阵，避免正交生成与透视回投造成的边缘收缩。

源 Quad 只生成投影纹理，不再直接画到观察视图；绘制排序代替旧的悬空高度偏移。真实接收几何参与表面光和遮挡，不用于确定角色内容的位置。内容根据确认布局生成，所以识别尚未确认时仍可能停留在旧目标。

固定测试图片 `CalibrationPattern` 绕过内容生成，按普通幻灯片投射。改变高度或镜头会改变其光斑，这是用于检查光路的正常行为；校正角色内容则会重新生成预畸变输出。

## 测量方式

验收测量 RGB 中的实际光斑中心与公开目标位置的误差，不再使用“构造坐标相同，所以误差为零”的接口。覆盖中心、四角、显式高度 0/1/2、正投、斜投和改变 FOV；高度来自测试 fixture，不代表已经识别多层。

```powershell
pwsh -File Tests/RunSimulationDualWindowChecks.ps1 -CheckClass PhysicalProjectorChecks
```

2026-11-06 最后记录为 75 项通过、45 个光斑位置，最大误差约 0.01348 格。源图与测量记录的位置见 [验证摘要](verification/current-simulation.md)。这不是实物毫米精度，也不是所有位置或材质的误差保证。

## 限制

几何未知、表面超出光锥或被遮挡时不能保证可见与贴合。当前未完成多层高度观测、镜头畸变/失焦、实机内外参和响应标定、快门积分及设备延迟验证。Gamma 下的反射与衰减是可控近似。

参数和当前识别模式以 [固定投影仪手册](physical-projector-guide.md) 为准；历史讨论中的亮度、模糊、硬件布局建议没有自动成为已实施功能。

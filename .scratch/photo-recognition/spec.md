# 真实照片识别接入

用户要求：加入真实照片识别。2026-10-08 用户确认暂无实拍照片；积木颜色、尺寸和视觉阈值尚未实测。

## 本次交付

- Unity 内导入本地 PNG/JPG 或用摄像头拍摄单张照片，处理过程离线。
- 配套 10×10 格纸带四角编码定位标记；按标记确定格纸方向，通过投影变换恢复每个格的位置。
- 首次从照片采样格纸与核心/墙/塔的三种实际颜色，保存标定配置；识别模块报告物理颜色编号，角色映射留在关卡规则中。
- 逐格输出空/占/不确定、独立积木编号、颜色、置信分数和照片证据；不确定或标记不完整时拒绝。
- 识别后展示只读 10×10 数字地图；用户核对并确认后进入现有关卡生成与出生点选择流程。
- 保留模拟布局；失败扫描不覆盖当前三维地图。
- 提供按实测积木边长生成可打印 SVG 格纸的工具，以及操作说明。

## 验证

合成像素图只用于自动检查，不能代表实物识别准确率。检查照片像素到扫描数据、旋转、透视、同色相邻、缺标记、颜色不确定、跨格混色、标定缺失的行为；回归现有寻路；验证 Unity 脚本编译及图片解码到关卡的连接。

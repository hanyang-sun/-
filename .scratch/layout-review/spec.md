# 地图校对与两项正确率

用户已于 2026-10-12 同意实施。流程：识别 → 草稿预览 → 实物校对并确认 → 自由设计 → 发布关卡 → 选择出生点 → 战斗。

- 原始检测记录和照片证据保持快照，允许已完成的拒绝扫描进入人工校对；格式无效输入仍不自动进入战斗。
- 支持添加、删除、改角色对应颜色、单块移动、整体按格平移、撤销、恢复；越界或目标占用不覆盖已有块。
- 实物校对阶段逐块对照照片；稳定 ID 表示同一个实物，补加/删除用于漏检/误检，移动保留 ID。
- 确认实物布局冻结真值与统计。识别正确率=匹配且颜色一致 / 真值总块数；位置正确率=匹配且相对格位一致 / 真值总块数，补加块计为原始位置错误，误检另报。
- 相对坐标约定固定为 min(C)=1、min(R)=1，各布局独立按此约定表示；整体平移不计相对位置错误，不做拟合真值的任意旋转或平移。
- 自由设计不修改真值或统计；可以返回重新校对，需要重新确认。
- 预览不要求核心或路线；生成关卡要求结构完整与核心，路线检查允许保留无路预览并在选择出生点/战斗启动时约束。
- 保存 Scans/<scanId>/review-<reviewId>.json，包含原始、真值、最终草稿、统计、编辑记录、确认时间与发布状态，原 result.json 不被改写。
- 以原照片为人工评价依据；用户确认数据不等同独立正式数据集的验收。

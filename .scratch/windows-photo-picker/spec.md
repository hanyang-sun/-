# Windows 导入照片按钮修复

日期：2026-10-12。

## 最小复现

v1.3.0 Windows Player 启动→扫描积木→不填路径点击导入。期望系统选图窗口，实际无窗口/无反馈。`PhotoFileSource` 只有 Editor 安装的选图委托；Player 直接读取空输入。Import 在空字符串分支返回。

## 调试流程

采用 diagnosing-bugs 的真实程序回归。已有源码展示确定的空路径返回分支，因此跳过大范围二分和额外诊断日志；最小复现仅需空路径点击一次，原生窗口断言可由工具自动运行。先在旧版本运行并观察失败，再修改并在新 Player 验证同一断言。

## 验收

- Windows 点击立即出现原生图片选择窗口，不再依赖填写路径。
- PNG/JPG/JPEG 图片筛选，中文和空格路径正确传递。
- 首次取消显示反馈，已有照片再次选图取消后保持原图，原地图不替换。
- UI 捕获选图失败，不将错误带出 OnGUI。
- Editor 保持已有选图委托；Windows P/Invoke 不参与 Android 编译。
- 交付含修复的 v1.3.1 EXE 与完整 ZIP，更新说明。

# 手机手势与地图缩放

## 操作

- 电脑：左键选出生点，右键拖动旋转，滚轮缩放。
- 手机：轻点选出生点，单指拖动旋转，双指捏合缩放；按钮可点击。
- 相机控制卡加入 - / + 和当前倍率；Reset 恢复 55°斜俯视及 100% 全图。
- 缩放范围 65%—250%，围绕棋盘中心，始终为正交投影；放大用于查看局部。
- UI 起始手势不操作地图；拖动、捏合、取消不选出生点；多指操作后全指抬起再开始下一手势。
- 照片页、失焦和禁用组件结束手势，触摸模拟鼠标不会重复操作地图。

## 验证结果（2026-10-11）

- Windows / Unity 6000.3.24f1 隔离工程编译通过。最终日志 `unity-check-fixed.log`（本地忽略），退出 0，包含 TOUCH_FRAME_CHECKS_PASSED 和 ORBIT_CAMERA_CHECKS_PASSED。
- 真实 Game 视图事件验证：滚轮、加/减按钮、65%/250%边界、Reset、旋转及每帧更新后的缩放保留、UI 上滚轮不缩放、宽屏最大缩放选格 `(9,9)`、窄屏缩放及旋转后手势选格 `(10,9)`。默认/缩放后仍为正交，远近同尺寸包围盒一致。
- 在实际 DemoUI.HandleTouches 入口注入 Touch 帧，验证轻点在抬起时确认、小抖动不旋转、单指拖动不选格、双指张开/收拢、一指静止仍有效、fingerId 顺序变化、两指退回单指不跳变、UI 起始、三指、替换触点、取消、越界、失焦、暂停、照片页开关及触摸模拟鼠标的重复选择隔离。
- 自动检查使用固定 1280×800 / 540×800 取景。原 Free Aspect 模式会瞬时改变取景高度，造成模拟点击不稳定；核对 UnityCsReference 的 GameViewSize/GetGameViewSize 接口后，仅在隔离进程内暂时改变内置尺寸，退出前恢复，不新增或保存尺寸偏好。按钮和照片页操作等待实际渲染帧再断言，没有为自动检查修改产品输入分支。
- 保存默认、250%放大、65%缩小和115%窄屏转向的四张 PNG；默认、放大及窄屏视觉复查通过，见 verification/README.md。放大围绕棋盘中心，边缘可能不在当前取景内，Reset 恢复全图。
- 未改变场景、原有 .meta GUID、输入设置、Packages、识别、寻路或照片标定。新增手势与布局脚本均有 .meta；git diff --check 通过。当前修改保存在本地工作区。

Android APK、原生触摸驱动、设备 DPI/安全区域及实际手感仍未验收；Touch 帧注入与 Windows 窄屏画面不代表手机真机测试。后续安装 Unity Android Build Support 后，打包到手机验证上表操作、按钮触控、照片标定及暂停/恢复。

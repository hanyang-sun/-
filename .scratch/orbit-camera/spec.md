# 棋盘视角旋转

用户要求：当前版本可以转动视角。

## 操作与边界

- 地图页右键拖动：水平绕棋盘中心旋转，垂直调整俯仰（45°—75°）。默认斜俯视：yaw -45°、pitch 55°，同时看到积木顶面和侧面。
- 左右各 45°、Lower/Higher 各 10°以及 Reset 按钮；Reset 恢复当前默认视角。
- 左键选择出生点；旋转、复位不改变地图、路线或出生点。
- UI 上不能发起旋转；照片页停止旋转；抬起、离开窗口、失焦结束拖动。
- 每次应用相机位置时保证正交投影，同尺寸积木不随远近改变显示尺寸；宽屏及窄屏完整容纳棋盘。
- GitHub 检索比较与 MIT 采用声明先于编码完成，见 docs/research/orbit-camera-github.md。

后续新增的缩放、手机手势与最新验证见 ../touch-zoom/spec.md；旋转和正交投影继续使用本功能的相机。

## 验收

真实 Unity Game 视图事件验证右键水平/俯仰、角度限制、按钮、复位、松开和 UI/照片页隔离。旋转后点选已知空格得到正确 GridPoint；例子切换后视角保留；地图数量/路线不因转动而变化。检查宽屏与窄屏实际截图及 Unity 编译日志。

## 桌游视角修正（2026-10-11）

用户选择斜俯视并要求无近大远小。原版已使用正交相机，本次将运行时投影保证移入 Apply，并将默认俯仰改为 55°、范围收紧至 45°—75°。GitHub 前置比较追加在原研究记录。需验证不同深度同尺寸积木的屏幕包围盒相等、主动切换透视后旋转及每帧更新恢复正交，并复查既有 Game 视图操作及宽窄屏截图。

首次调整检查通过后，截图暴露底部控件遮挡棋盘尖角；正交半高下限调整到 21，保持旋转时取景尺度固定，并新增底部控件留白检查。

# 多出生点与删除相机按钮

用户授权：自主选择多个敌人出生点；删除旋转和缩放 UI。

Completion: complete (2026-10-11)

这是对 requirements-v1.md 单出生点条款的扩展。保留固定地图、四方向最短路、核心共血、手动波次和战斗锁定。相机保持正交投影及鼠标/手机手势。

## 验收

- 战斗前，点击/轻点空格添加；再次点击已选格删除。默认入口 (1,18) 可以取消，允许清空后重新选择。
- 新点被占用、越界或无路时保留原选择并提示；零入口或已有无效入口不可开局。
- 每个入口有编号和独立路线；每波数量是总数，按选中顺序轮流分配，跨波继续轮转；敌人沿所属路线移动。
- 战斗锁定全部入口，暂停与重试正常；重试重置轮转计数。
- 删除 Left/Right/Reset/Lower/Higher/-/+ 相机控件及隐藏输入区域；鼠标拖动/滚轮、手机拖动/捏合正常。
- 纯 C# 回归与隔离 Unity 实际宽屏/竖屏操作检查通过。
